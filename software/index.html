Projects

natalityr

An R package for preparing and classifying CDC NVSS natality microdata from 2016–2024. Provides functions for birth classification; data importation and filtering; and cesarean rate summaries.

This package demonstrates a cross-language integration between R and Python, using libraries such as pyarrow and reticulate. This process extracts selected variables and converts the resulting data to a Parquet format for efficient storage and access within R.
